AOTAVSEC Salary Calculator — PWA/Offline companion

ไฟล์
- index.html: แอปหลัก (คงปฏิทินลงเวลา ประวัติสลิป รายงาน CSV และสูตรเดิม)
- manifest.webmanifest + sw.js: ติดตั้งเป็นเว็บแอปและแคชหน้าเว็บ/ไฟล์ที่เคยเปิดเมื่อออนไลน์
- icons/: ไอคอนสำหรับ Android

ติดตั้งเป็นแอป Android
1. อัปโหลดโฟลเดอร์ AOTAVSEC_PWA ไปยังเว็บโฮสต์ HTTPS ที่คุณควบคุม เช่น GitHub Pages หรือโฮสต์ HTTPS ส่วนตัว
2. เปิด URL ของเว็บนั้นใน Chrome บน Android และเปิดให้โหลดหน้าเว็บจนเสร็จอย่างน้อยหนึ่งครั้งขณะออนไลน์
3. เปิดเมนู Chrome (⋮) แล้วเลือก “ติดตั้งแอป” หรือ “เพิ่มลงในหน้าจอหลัก” (คำที่แสดงอาจต่างกัน)
4. เปิดแอปจากไอคอนบนหน้าจอ; ข้อมูลการลงเวลาและประวัติใน PWA จะบันทึกใน localStorage ของเบราว์เซอร์/แอปนี้

ข้อจำกัดการออฟไลน์และการซิงก์
- ต้องเปิดหน้าเว็บอย่างน้อยหนึ่งครั้งขณะออนไลน์เพื่อให้ service worker แคชไฟล์ได้; CDN ภายนอกอาจยังไม่พร้อมออฟไลน์จนกว่าจะถูกโหลดและแคชสำเร็จ
- โหมด PWA ที่โฮสต์แยกจาก Google Apps Script ใช้ Google Sheets อัตโนมัติไม่ได้โดยตรง เนื่องจากไม่มี google.script.run; ใช้ “สำรองข้อมูล JSON” แล้วนำไฟล์ไป “กู้คืน/นำเข้าข้อมูล” ใน Web App ของ Apps Script เมื่อออนไลน์เพื่อส่งรายการไปยัง Sheets
- การย้ายกลับจาก Sheets ไปยัง PWA ให้เปิด Web App, ส่งออก JSON แล้วนำเข้าใน PWA; การนำเข้าเป็นแบบรวมข้อมูล ไม่ลบรายการเดิม
- แอปที่โฮสต์ใน Apps Script ยังคงใช้ Google Sheets ได้ตามเดิม แต่การทำงานออฟไลน์แบบติดตั้ง PWA จะรองรับได้จำกัดกว่าเว็บโฮสต์ HTTPS แยกต่างหาก
- localStorage ไม่ใช่ระบบสำรองถาวร หากล้างข้อมูลเว็บ/ถอนการติดตั้ง ข้อมูลในเครื่องอาจหาย ควรส่งออก JSON เป็นระยะ

สูตรที่สำคัญ
- OT: อัตราเดิม (รายรับรายวัน ÷ 8) × ตัวคูณที่เลือก × ชั่วโมง OT; ค่าเริ่มต้นตัวคูณ 1 เท่าเพื่อรักษาผลลัพธ์เดิม
- ประกันสังคม: ใช้สูตร 5% และเพดานตามปีที่โค้ดตั้งไว้; ฐานค่าจ้างที่นำมาคิดคือเงินเดือนฐาน + รายรับรายวัน × วันทำงาน ตามการตั้งค่าเดิมในโค้ด
- ภาษีอัตโนมัติ 2% เป็นสูตรเดิมในแอป ไม่ใช่คำยืนยันว่าเป็นภาษีหัก ณ ที่จ่ายที่ถูกต้องสำหรับทุกกรณี
- ตัวคูณ OT และฐานประกันสังคมควรตรวจสอบกับเงื่อนไขการจ้าง/ฝ่ายเงินเดือนก่อนใช้เงินจริง
